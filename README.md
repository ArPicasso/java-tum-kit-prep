# Java practice before TUM

My Java exercises from the summer of 2026, written to prepare for the first-semester programming modules at TUM (EIDI and PGDP). One folder per day, from the first `Hello` to classes, inheritance and file reading.

This is a learning log, not a finished product. Folder and class names are in German because the course I followed is in German.

## What is inside

| Folder | Content |
|:--|:--|
| `ProgrammierenLernenVonJonasKeil/Tag1` to `Tag9` | Variables, conditions, `Scanner`, loops, arrays, `Random`, methods, a first small console game |
| `Tag10` to `Tag14` | Classes and objects, constructors, return values, overloading, getters and setters |
| `Tag15` to `Tag20` | Review exercises, for-each, `break` and `continue`, `switch`, conditional operators, `printf` |
| `Tag21_DoubleArrays` | 2D arrays and a **console Tic-Tac-Toe** for two players that I designed and wrote on my own |
| `Tag22_FileReading` | Reading text files |
| `Tag23_Ueberschreibung` | Inheritance and method overriding |
| `ClaudeKurs/` | Extra exercises I asked Claude to set for me, for example a small warehouse model |
| `Projects/` | Empty Maven project skeleton |

## How to run

The repository is an IntelliJ IDEA project: open the folder and run any class with a `main` method.

From the command line, for example the Tic-Tac-Toe game:

```bash
cd ProgrammierenLernenVonJonasKeil
javac Tag21_DoubleArrays/*.java
java Tag21_DoubleArrays.TicTacToe
```
